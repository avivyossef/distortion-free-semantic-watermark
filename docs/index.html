TL;DR

Draw several images, then keep one whose meaning hashes to a code favored by a secret key. Averaged over keys, the output is exactly the generator's distribution, only black-box sampling is needed, and detection survives edits that preserve content.

The sampling rule, step by step

A toy two-dimensional version. The paper uses 256-dimensional encoder embeddings and up to 12 bits.

N
M
  1. 1Sample. Draw N images for the prompt. The generator is only sampled, never opened.
  2. 2Hash the meaning. Embed each image; its M-bit code says which side of each random hyperplane it falls on.
  3. 3Score with the key. A keyed pseudorandom function gives every code a score in [0, 1).
  4. 4Select. Gumbel selection: the code maximizing log F(c) / nc wins, and one of its images is drawn uniformly.

Abstract

We present a provably distortion-free semantic watermarking algorithm that requires only black-box sampling access to a generative model and black-box access to a semantic embedding. A watermark is called distortion-free if, averaged over its secret detection key, it leaves the generator's output distribution unchanged; this provides a formal guarantee that watermarking does not reduce output quality. Conventional such watermarks are often brittle to transformations, which is especially problematic for images, where benign operations such as compression, cropping, or resizing substantially change the entire pixel representation. Semantic watermarks therefore require detection to be robust to transformations that preserve content.

Previous methods combining these properties rely on white-box properties of the underlying model: autoregressive text generation, or diffusion-specific access such as control of the initial noise or diffusion inversion. In contrast, our construction is fully generic: it interacts with the generative model and the semantic embedding only via sample and query access. We instantiate this framework for image generation, characterize the two competing properties required of the semantic embedding (stable under content-preserving transformations, yet distinct across independent generations of the same prompt), and train an image encoder directly for this trade-off. The encoder improves separation while maintaining stability over off-the-shelf alternatives, and enables strong aggregate detection that remains robust to various transformations. Because it needs only black-box access, the scheme works on both open-source and closed models.
