About

We introduce a sampling-based, distortion-free watermark for generative models and evaluate it on image generation. To our knowledge, it is the first distortion-free semantic watermark that treats both the generator and the semantic encoder as black boxes. The method only needs to request samples and encode them, so it can work with a closed generation API. The choice of encoder determines which changes to an image the watermark can tolerate.

How it works. We ask the generator for several images of the same prompt. An image encoder describes each candidate, and random hyperplanes turn that description into a short code. A secret key gives each code a score. Our selection rule uses those scores and accounts for how many candidates share each code, then returns one of the original images with its pixels untouched.

Why it’s distortion-free. For any given prompt, averaging over randomly drawn secret keys gives exactly the same distribution of images as sampling directly from the generator.

Why it can survive edits. Cropping, resizing, and compression can change many pixels while preserving what an image depicts. When an edit leaves the encoder’s description nearly the same, the detector can check the image’s code and nearby codes for the watermark signal.

How we detect it. We use the same key to score a batch of images from one source. The encoder is trained to give similar descriptions to an image and its edited versions while distinguishing different images from the same prompt. A single image can carry a weak signal, so we combine evidence across the batch.
