Distortion-Free Semantic Watermarks for Black-Box Generative Models

Ask the model for several images and let a secret key choose which one to return. The result is an ordinary sample from the model, untouched. The key holder can still detect the choice later, even after edits that keep what the image shows.

Aviv Yossef, Or Patashnik, Or Zamir
Tel Aviv University

How it works

1

Ask the generator for six images

Same prompt, six independent samples. We never touch the model's weights or its sampling. Any text-to-image API works.

Change the prompt or the model at the top of the panel at any time. Every step updates.

2

Describe each image with an encoder

A semantic encoder turns every image into an embedding. Here the six embeddings are projected to 2D so you can see them. Images that look alike land close together.

3

Cut the space into codes

Random hyperplanes split the embedding space. Each line contributes one bit, depending on which side an image falls, so every image gets a short code. Images in the same region share a code.

4

Score each code with a secret key

A keyed hash gives every code a score between 0 and 1. Without the key, the scores look random.

5

Return one image, pixels untouched

The codes race: the highest log(score) / group size wins, and one image from that group is returned as is. High-scoring codes usually win. Larger groups get a head start, which is what keeps the output fair.

Race values for this key

6

Across keys, nothing changes

Each key favours some images. Averaged over random keys, every candidate is returned equally often, exactly as if you had sampled from the model directly. That is what distortion-free means.

7

Detect it from a batch

Take a few images from one source and score each image's code with the key. Near a line, the neighbouring code is tried too, so small edits don't break it. Images chosen with the key score higher than chance on average. One image is weak evidence, so we average over a batch.

The walkthrough uses six pre-generated candidates per prompt and a simplified 2D projection centred on each prompt. The paper hashes full encoder embeddings and calibrates detection on a separate clean set.

Why it works

Black-box

The method only requests samples and encodes them, so it works with a closed generation API. To our knowledge it is the first distortion-free semantic watermark that treats both the generator and the encoder as black boxes.

Distortion-free

For any prompt, averaging over random secret keys gives exactly the same distribution of images as sampling the generator directly. No pixel is changed.

Survives edits

Cropping, resizing, and compression change pixels but not what an image depicts. The encoder is trained to describe an image and its edited versions alike, so the image's code, or a nearby one, still carries the signal.
